# fetchepoch

Fetch identifiers and epoch tokens for idempotent workflows.

**Site:** https://theworker02.github.io/fetchepoch/

## Install / run

```bash
git clone https://github.com/theworker02/fetchepoch.git
cd fetchepoch
node src/cli.js
node --test
```
